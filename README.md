## Cycling
`cycling` is an experimental project focused on **indoor cycling and training scenarios**.  
It integrates **Bluetooth sensors (Magene S3+)**, **Python (BLE)**, **MQTT**, and a **Node-RED dashboard** to
collect, process, and visualize real-time cycling data such as **cadence** and **speed**.

The project also includes a lightweight front-end simulation setup using **JSON configuration files and a video player**,
allowing multiple stationary bikes to be displayed and interacted with simultaneously.

`cycling` 是一個以 **室內健身車 / 自行車訓練** 為核心的實驗性專案，整合了  
**藍牙感測器（Magene S3+）＋ Python（BLE）＋ MQTT ＋ Node-RED Dashboard**，  
用來即時蒐集、處理並視覺化「踏頻（Cadence）與速度（Speed）」等騎乘數據。

本專案同時也包含前端模擬設定（JSON + Video Player），可用於多台健身車同步顯示與互動場景。
